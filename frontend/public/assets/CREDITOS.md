# Creditos de assets 3D

Todos los modelos, texturas y HDRI de esta carpeta vienen de [Poly Haven](https://polyhaven.com)
con licencia **CC0** (dominio publico: se pueden usar, modificar y distribuir sin atribucion obligatoria).
Se descargan y optimizan con `npm run assets` (ver `scripts/fetch-assets.mjs`).
